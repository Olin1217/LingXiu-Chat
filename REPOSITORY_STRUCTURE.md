# Repository structure

- `LingXiu/`: iOS/iPadOS SwiftUI app source
- `LingXiuTests/`: unit and interaction tests
- `Server/`: HTTPS proxy, migrations, deployment files and checks
- `Documentation/`: product requirements and infrastructure notes
- `Scripts/`: simulator trust and regression helpers
- `Backups/`: historical project snapshots

Local Xcode user data and build output are intentionally excluded.
